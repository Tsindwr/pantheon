# pantheon

# install everything
`pnpm install`

# build all shared packages and apps
`pnpm build`

# run one app
`pnpm dev:gauntlet`

# run another app
`pnpm dev:creosmark`

# check one package
`pnpm --filter @sunderttrpg/core check`

# build one app
`pnpm --filter @sunderttrpg/gauntlet build`

# run all dev servers
`pnpm dev`
